イルフプラザこどもカード発行 PWA版（Ver.1.4ベース）

【公開手順】
1. このフォルダー内の index.html / manifest.webmanifest / sw.js / icon-192.png / icon-512.png を、HTTPSで公開できる静的Webホスティングの同じフォルダーへアップロード。
2. 公開URLの末尾 /index.html をスマホのChromeまたはSafariで開く。
3. Android Chrome: メニュー →「アプリをインストール」または「ホーム画面に追加」。
   iPhone Safari: 共有 →「ホーム画面に追加」。
4. スタッフには公開URLをLINE等で送るか、公開URLからQRコードを作成して配布。

【重要】
・公開するのはアプリの静的ファイルのみ。子どもの名前、顔写真、生年月日を公開・アップロードしない。
・HTTPSが必要。HTMLファイルをスマホに送るだけではPWAとしてインストールできない。
・オフライン起動のため、アプリ本体（個人情報を含まない静的ファイル）は端末にキャッシュされる。
・個人情報はブラウザメモリで扱い、LocalStorageやIndexedDB等には保存しない。
・印刷履歴、OS/ブラウザの一時データ、スクリーンショット、プリンターの内部履歴まで完全消去は保証できない。
・印刷後のデータ消去はブラウザのafterprintイベントに依存。OSによっては発火しない場合があるので、必ず「入力を初期化」も利用し、アプリを閉じる。
・公開先にアクセス解析・広告・外部スクリプトを追加しないこと。
・共有URLを知っている人がアプリ自体にアクセスできる。スタッフ専用アクセス制限が必要ならホスティング側で別途設定すること。
・印刷倍率100%、余白なし、ヘッダー・フッターなし。専用紙で実機テストが必要。
